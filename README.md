# Antiyoy Online

Онлайн-мультиплеер (не hotseat!) клон пошаговой стратегии **Antiyoy** на гексах.
Написан на **Node.js** (сервер — авторитетная игровая логика + WebSocket) и
**ванильном JS + HTML5 Canvas** на клиенте. Друзья заходят на сайт, создают
комнату, делятся 4-значным кодом — и играют каждый со своего устройства.

## Возможности

- **Аккаунты (логин/пароль).** Сайт недоступен без входа. Пароли хранятся в
  SQLite в виде scrypt-хеша. Учётки заводит администратор скриптом.
- Настоящий онлайн-мультиплеер 2–6 игроков через WebSocket (комнаты по коду).
- Сервер хранит и валидирует всё состояние — читерить с клиента нельзя.
- **Настройки лобби:** хост меняет размер карты и число игроков прямо в лобби
  (до старта), остальные видят их в режиме «только чтение».
- **Реконнект:** место в партии привязано к аккаунту. Вылетел / закрыл вкладку /
  зашёл с другого устройства — сервер сам возвращает вас в ту же игру.
- Адаптивный интерфейс: мышь (ПК) и тач (телефон/планшет) — пан, зум, тапы.
- До **8 игроков** в комнате.
- Опции лобби: размер карты, число игроков, **деревья вкл/выкл**,
  **таймер хода** (выкл / 30 / 45 / 60 сек — при истечении ход завершается сам).
- Подсветка своей территории, когда сейчас твой ход.
- **Отмена действий** в рамках текущего хода (кнопка ↶).
- Покупка из выпадающих списков: **Юниты**, **Постройки**, **Заклинания**.
- **Бестиарий** (кнопка ℹ сверху) — описание всех юнитов, построек и заклинаний.
- Реализованы основные правила Antiyoy:
  - Провинции (связные группы ≥2 гексов), столицы, общий баланс монет.
  - Доход: +1 за гекс, +4 за ферму, −1 за дерево, минус содержание юнитов.
  - Базовые юниты: крестьянин(1) → копейщик(2) → барон(3) → рыцарь(4)
    (объединение двух одинаковых). Цена покупки = 10×уровень. Содержание:
    2 / 6 / 18 / 54 монеты в ход.
  - **Всадник** — сила копейщика (ур. 2), но дальность хода ×~1.5 (рейды на 2
    гекса). Цена 25, содержание 10. Не объединяется.
  - **Лазутчик** — ур. 1, цена 15, содержание 4. **Скрытность:** невидим врагам,
    пока не окажется рядом с их территорией. **Не захватывает землю** — чистый
    разведчик. Враг видит лазутчика на своей земле (цветной маркер юнита).
  - **Призыватель** — ур. 2, цена 35, содержание 12. Раз в ход бесплатно
    призывает **волка** (TTL 2 хода, сила 1, бесплатное содержание, не
    объединяется) на соседнюю свою клетку.
  - **Барон на орле** — ур. 4, цена 120, содержание 18. Рейдовый воин:
    **высаживается в любую клетку карты** (если пробивает защиту), с анимацией.
    Вне своей территории живёт 3 хода.
  - **Радиус хода:** юниты ходят до 4 клеток по своей территории (всадник —
    дальше, до 6). Захват — в пределах досягаемости от пройденного пути.
  - Юниты не встают на постройки (кроме фермы); в чужие/свои здания — нельзя.
  - **Рыцарь (ур. 4) пробивает рыцаря** (равный 4-й уровень).
  - Юниты на оторванной от провинции одиночной клетке (без финансирования)
    живут максимум 3 хода, затем гибнут.
  - **Заклинания** (платятся из казны провинции, бьют по любой клетке) — с
    анимацией, видной всем, и отметкой в чате «кто на кого»:
    **Громовой удар** (30) — оглушает врага на ход; **Метеор** (60) —
    уничтожает юнита (до ур.3) или постройку, без захвата (вылетает из вашей
    провинции); **Землетрясение** (180) — ломает все укрепления в области 3×3.
  - **Баллиста** — ставится как башня, не ходит; раз в ход бьёт по вражескому
    юниту в радиусе 2 (уничтожает всё до 3-го уровня; рыцарь ей не по зубам).
    Защита уровня 3, ломается рыцарем (ур. 4). Цена 80, содержание 45.
  - **Улучшения державы** (вкладка «Держава», один раз за игру): *Аграрная
    реформа* (200) — доход со всех ваших ферм удваивается (+8 вместо +4).
  - Защита: замок=1, башня=2, сильная башня/баллиста=3, юнит=его уровень
    (+соседи). Захват возможен, если уровень атакующего **строго больше** защиты
    (исключение — рыцарь против рыцаря).
  - **Экономика скрыта:** вы не видите казну и доход чужих провинций.
  - Банкротство провинции → все её юниты гибнут (надгробия → деревья).
  - Постройки: фермы (рядом со столицей/фермой, дорожают), башни, сильные башни,
    баллисты.
  - Деревья (если включены) растут и распространяются; захват дерева даёт +3.
  - **Игрок выбывает**, когда у него не осталось ни одной столицы (только
    одиночные клетки) — его земли становятся нейтральными.
  - **Чат** в игре (кнопка 💬): имена подсвечены цветом игрока.
  - Победа — когда остаётся один игрок со столицей. Хост может **завершить
    игру** в любой момент и вернуть всех в лобби.

## Как играть

1. Откройте сайт. Введите имя.
2. **Создать игру** → получите код комнаты. Либо **Войти** по чужому коду.
3. Когда все собрались, хост жмёт **Начать игру**.
4. В свой ход:
   - Тапните свою провинцию — снизу появятся баланс/доход и кнопки.
   - **Крестьянин (10)** → затем тапните клетку: пустую свою / своего юнита
     (объединение) / соседнюю слабую клетку (захват).
   - **Ферма / Башня / Сильная башня** → тапните свою клетку.
   - Тап по своему юниту подсвечивает, куда он может пойти/кого захватить.
   - **Завершить ход**.

## Аккаунты

Зарегистрироваться на сайте нельзя — учётки заводит администратор. Пароли
хешируются (scrypt), поэтому добавляйте пользователей **скриптом**, а не голым
SQL:

```bash
node scripts/adduser.js <логин> <пароль>
# или: npm run adduser -- <логин> <пароль>

# примеры
node scripts/adduser.js alice secret123
node scripts/adduser.js bob   hunter2
```

Повторный запуск с тем же логином **меняет пароль**. База лежит в SQLite-файле
(`data/antiyoy.db` по умолчанию, путь меняется переменной `DB_PATH`). Логин —
он же отображаемое имя по умолчанию (никнейм в игре можно поменять).

В Docker запускайте скрипт внутри контейнера (см. ниже).

## Запуск локально

```bash
npm install
node scripts/adduser.js alice secret123   # создать хотя бы одного пользователя
npm start
# откройте http://localhost:3000 — увидите страницу входа
# (для теста мультиплеера заведите 2 учётки и войдите в разных браузерах/окнах инкогнито)
```

## Развёртывание на сервере (хостинг)

### Вариант A — Docker (рекомендуется)

```bash
docker build -t antiyoy-web .

# том antiyoy-data хранит SQLite-базу с аккаунтами между перезапусками
docker run -d --restart=unless-stopped -p 80:3000 \
  -v antiyoy-data:/data --name antiyoy antiyoy-web

# завести пользователей (внутри контейнера, БД на /data)
docker exec -it antiyoy node scripts/adduser.js alice secret123
docker exec -it antiyoy node scripts/adduser.js bob   hunter2
```

Теперь игра доступна по IP/домену вашего сервера. Для HTTPS (нужен для `wss://`
на публичном домене) поставьте перед контейнером reverse-proxy, напр. Caddy:

```
yourdomain.com {
    reverse_proxy localhost:3000
}
```

Caddy сам получит TLS-сертификат, а WebSocket проксируется автоматически.
При работе по HTTPS задайте серверу `COOKIE_SECURE=1`, чтобы cookie сессии
помечалась флагом `Secure`.

### Вариант B — напрямую через Node + systemd

```bash
npm install --omit=dev
PORT=3000 node server/index.js
```

Пример unit-файла `/etc/systemd/system/antiyoy.service`:

```ini
[Unit]
Description=Antiyoy Online
After=network.target

[Service]
WorkingDirectory=/opt/antiyoy
ExecStart=/usr/bin/node server/index.js
Environment=PORT=3000
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

Затем `systemctl enable --now antiyoy` и проксируйте через Nginx/Caddy с
поддержкой WebSocket (`Upgrade`/`Connection` заголовки) для HTTPS.

### Переменные окружения

- `PORT` — порт HTTP/WebSocket-сервера (по умолчанию `3000`).
- `DB_PATH` — путь к файлу SQLite с аккаунтами (по умолчанию `data/antiyoy.db`,
  в Docker — `/data/antiyoy.db`).
- `COOKIE_SECURE` — `1`, чтобы cookie сессии помечалась `Secure` (для HTTPS).

## Структура проекта

```
server/
  game.js     # игровая логика (карта, провинции, ходы, бой, сериализация)
  index.js    # Express + WebSocket, аутентификация, комнаты, ходы
  db.js       # SQLite: пользователи (scrypt) и настройки
  auth.js     # сессии (подписанные cookie), проверка входа
scripts/
  adduser.js  # CLI для добавления/смены пароля пользователя
public/
  login.html / login.js  # страница входа
  index.html  # меню, лобби, игровой экран
  style.css
  app.js      # сеть, рендер на Canvas, управление
Dockerfile
```

## Замечания / возможные доработки

- Сейчас нет ИИ-ботов — игра рассчитана на людей. Можно добавить.
- Туман войны и дипломатия из оригинала не реализованы (база геймплея — есть).
- Балансные числа близки к оригиналу, но при желании легко правятся в
  `server/game.js` (константы вверху файла).
